# Расписание АПТ

**Человеческое расписание Альметьевского политехнического техникума.**
Данные берутся с официального `almetpt.ru`, а показываются так,
как это должно выглядеть в 2026 году: живая пара с таймером, замены,
домашка, подгруппы, поиск по преподавателям, календарь и офлайн на телефоне.

## Что это

Сайт техникума отдаёт расписание тяжёлыми страницами, без поиска, без
подгрупп и без понимания «а что у меня сейчас». Этот проект забирает те же
данные ботом, раскладывает их в компактный JSON и рисует быстрый интерфейс,
который работает даже без интернета.

| Режим | Как запускается | Откуда данные |
|---|---|---|
| **Статический** | GitHub Pages, папка `docs/` | JSON-файлы, которые раскладывает бот раз в 30 минут |
| **Живой** | `python3 server.py` | парсинг `almetpt.ru` на лету |

Фронтенд сам определяет режим по `GET /api/health` — один и тот же `index.html`
работает и там, и там.

## Возможности

<table>
<tr><td width="33%" valign="top">

### 🕒 Живой день
Текущая пара подсвечена, прогресс-бар, обратный отсчёт до конца пары или
до начала следующей. Панель «что сейчас» над расписанием. Всё время —
**по Москве**, независимо от часового пояса устройства.

</td><td width="33%" valign="top">

### 👥 Подгруппы
Пары по подгруппам — отдельными блоками: своя аудитория, преподаватель,
тема и домашка. Выбор «своей» подгруппы фильтрует день, неделю,
список домашних заданий и экспорт в календарь.

</td><td width="33%" valign="top">

### 🔍 Поиск
По преподавателю, аудитории, группе и предмету за любой день:
«где сейчас Зинкин», «кто в 233-й». Работает сразу по всем курсам.

</td></tr>
<tr><td valign="top">

### 📅 Календарь
Экспорт `.ics` на день или на неделю — с темой, аудиторией и преподавателем,
время в UTC. Импортируется в Google Calendar, Apple Календарь, Outlook.

</td><td valign="top">

### 📱 PWA
Ставится на телефон, работает офлайн (service worker кэширует оболочку и
данные), ярлыки «Сегодня» / «Неделя», свайпы между днями, safe-area
под вырезом, поля ввода 16px (иначе iOS зумит страницу).

</td><td valign="top">

### 🧑‍🏫 Преподаватели
Рядом с ФИО — фотография с сайта техникума и должность. Фото зеркалятся
в `docs/data/teachers/<id>.jpg`, поэтому работают офлайн. Нет фото —
кружок не рисуется вовсе.

</td></tr>
</table>

**Ещё:** обзор недели одним экраном • полоска недели с точками-количеством пар •
избранные группы (Shift-клик) • пометка замен и «основное расписание отсутствует» •
перемены и «окна» с подсчётом длительности • консультации и график учебного
процесса • копирование домашки списком • ссылки вида `#/1042/2026-10-05` •
светлая/тёмная тема • баннер, если зеркало давно не обновлялось.

### Горячие клавиши

| | | | |
|---|---|---|---|
| `T` сегодня | `W` неделя | `G` группа | `F` / `/` поиск |
| `R` обновить | `D` тема | `E` календарь | `?` подсказка |
| `←` `→` день | `Shift+←/→` неделя | `1` / `2` своя подгруппа | `0` обе |

### Почему не всё помечено «заменой»

На сайте техникума день складывается из **основного расписания** и **таблицы
замен**. У АПТ основное расписание в большинстве дней не выкладывается вообще —
весь день публикуется через таблицу замен, поэтому класс `changesPair` стоит на
каждой паре (проверено на живой странице: 1640 из 1641). Значок, который горит
всегда, ничего не сообщает, поэтому здесь он показывается только когда заменена
**часть** пар дня.

## Быстрый старт

```bash
git clone https://github.com/TheFlipper-spec/apt.git && cd apt
python3 server.py                  # http://localhost:8000
PORT=8080 python3 server.py
```

Зависимостей нет — нужен только **Python 3.9+**.

```

`make_demo.py` раскладывает уже сохранённые в `docs/` дни по текущей и следующей

</details>

```

</details>

## Архитектура

```
apt/
├── parser.py              # мини-DOM + парсеры страниц almetpt.ru
├── fetch_all.py           # бот: almetpt.ru -> docs/data/*.json
├── server.py              # живой режим: HTTP-сервер + прокси-парсер
├── static/                # исходники фронтенда
│   ├── index.html         #   весь интерфейс: разметка, стили, логика
│   ├── sw.js              #   service worker (офлайн)
│   ├── manifest.webmanifest
│   └── icons/
├── docs/                  # то, что раздаёт GitHub Pages (бот обновляет сам)
│   └── data/
│       ├── groups.json, bells.json, meta.json
│       ├── teachers.json          # справочник преподавателей
│       ├── teachers/<id>.jpg      # зеркало фотографий
│       ├── summary.json           # сводка «сколько пар» по всем группам
│       ├── checked.json           # журнал проверок (служебный)
│       ├── d/<groupId>/<date>.json
│       └── x/<date>.json          # срез дня по всем группам (для поиска)
├── data/                  # fallback-данные и дисковый кэш живого режима
├── tests/                 # парсер, бот, интеграция, вёрстка, фронтенд
└── tools/                 # иконки, фикстуры, демо-зеркало, шаблон workflow
```

<details>
<summary><b>Формат дня (JSON)</b></summary>

```jsonc
{
  "ok": true, "groupId": 1042, "group": "СА-231б",
  "date": "2026-10-05", "dateText": "понедельник, 5 октября 2026 года",
  "published": true,        // расписание на эту дату вообще выложено
  "baseMissing": false,     // «основное расписание отсутствует»
  "pairs": [{
    "n": "I", "num": 1, "start": "08:00", "end": "09:20",
    "room": "233", "roomTitle": "…", "subject": "…", "subjectFull": "…",
    "teacher": "…", "teachers": ["…"], "subgroup": "1 п/гр.",
    "topics": [], "homework": [], "notes": [],
    "changed": false, "variants": 2,
    "parts": [                      // заполняется, когда variants > 1
      { "subgroup": "1 п/гр.", "room": "233", "subject": "…",
        "teacher": "…", "topics": [], "homework": [], "notes": [] }
    ]
  }],
  "consultations": [], "graf": [], "notices": [],
  "fetchedAt": 1791100000, "stale": false
}
```

Плоские поля (`subject`, `teacher`, `room`) остаются для совместимости: при
нескольких подгруппах они склеены через ` · `, а интерфейс берёт `parts[]`.

</details>

### API живого режима

| Метод | Ответ |
|---|---|
| `GET /api/health` | проверка живости (по ней фронтенд выбирает режим) |
| `GET /api/groups` | `{ ok, groups:[{id,name,course}], fetchedAt, source }` |
| `GET /api/bells` | время пар |
| `GET /api/schedule?group=ID&date=YYYY-MM-DD` | день целиком (формат выше) |
| `GET /api/lessons?date=YYYY-MM-DD` | срез дня по всем группам — для поиска |

Справочник преподавателей в обоих режимах читается из статики.
Всё, что не `/api/`, сервер отдаёт как статику из `static/`.

## Тесты

```bash
python3 -m unittest discover -s tests          # 71 тест: парсер, бот, интеграция, CSS

npm i jsdom                                    # в любой папке
JSDOM_PATH=$PWD/node_modules/.package-lock.json \
  node --test tests/frontend.test.mjs          # 47 тестов интерфейса
```

Фронтенд тестируется в jsdom: страница реально загружается, `fetch` подменяется
файлами зеркала, после чего проверяется разметка и поведение. Скриншот в CI не
снять, поэтому мобильная вёрстка закрыта `tests/test_css_mobile.py` — он
разбирает CSS и ловит то, что ломается молча: колонки шире экрана, жёсткие
ширины, размер шрифта в полях (<16px → зум в Safari), зоны нажатия, отступы.

В `tests/fixtures/raw/` лежат две **настоящие** страницы almetpt.ru — на них
проверяется, что парсер не разойдётся с живой разметкой.

```bash
python3 tools/make_web_fixtures.py   # пересобрать фикстуры фронтенда
python3 tools/make_icons.py          # иконки PNG без зависимостей (~1 мин)
```

## Бот и GitHub Pages

`fetch_all.py` скачивает группы, звонки и расписание всех групп на окно дат и
складывает в `docs/data/`. Запускается по cron из `.github/workflows/update.yml`.

```bash
python3 fetch_all.py --weeks 2 --workers 6     # текущая + следующая неделя
python3 fetch_all.py --days=-2..7              # произвольное окно
python3 fetch_all.py --full                    # игнорировать TTL, перекачать всё
python3 fetch_all.py --keep-days 14            # сколько дней хранить
```

Готовый workflow лежит в `tools/update-workflow.yml`. Его нужно **скопировать
руками** — GitHub запрещает приложениям без права `workflows` писать в
`.github/workflows/`:

```bash
cp tools/update-workflow.yml .github/workflows/update.yml
git add .github/workflows/update.yml && git commit -m "обновление по расписанию" && git push
```

### TTL перепроверки

Свежесть считается по `fetchedAt` **внутри JSON** и журналу `checked.json`,
а не по mtime файла (после `actions/checkout` он у всех одинаковый — из-за
этого раньше дни навсегда застревали в состоянии «пар нет»).

| Дата | Перепроверять |
|---|---|
| сегодня | 10 мин |
| +1…+3 дня | 20 мин |
| дальше | 3 ч |
| прошедшая, опубликованная, с парами | 7 дней |
| прошедшая прочая | 12 ч |

Файл дня перезаписывается только если содержимое изменилось — бот не плодит
пустые коммиты. Индексы (`summary.json`, `x/*.json`) тоже пишутся через
сравнение и не содержат меток времени.

### Нюансы

- **Cron в Actions не точный** — запуски опаздывают на 5–30 минут.
- Запросы идут из дата-центров GitHub. Если almetpt.ru начнёт резать
  иностранные IP — поможет self-hosted раннер или живой `server.py`.
- Даты вне окна сборки показывают честное «за эту дату данных нет».
- Если сайт техникума недоступен, бот оставляет старые данные, а сайт
  показывает баннер «зеркало давно не обновлялось».

## Куда развивать

Подробный разбор с приоритетами, оценкой сложности и планом реализации —
в **[IDEAS.md](IDEAS.md)**. Коротко:

| | Идея | Зачем |
|---|---|---|
| 🔔 | **Push-уведомления** «через 10 минут пара» и «появилась замена» | главная причина открыть сайт — узнать об изменении, а сейчас за этим надо заходить самому |
| 🧩 | **Персональное расписание** (подписка на свои пары, скрытие лишнего) | у старших курсов половина дня — практика |
| 📡 | **Подписка на календарь по ссылке** (webcal/ICS-фид вместо разового экспорта) | один раз подключил — обновляется само |
| 🧠 | **Диффы расписания**: «что изменилось со вчера» | данные для этого уже есть в истории git |
| 🩺 | **Статус-страница бота** и алерт при `failed > 0` | в последнем прогоне 75 групп не скачались и никто этого не увидел |
| 🔎 | **Глобальный поиск по неделе**, а не по одному дню | «когда у меня физика на этой неделе» |
| 📊 | **Статистика**: окна, нагрузка по дням, часы по предметам | полезно и старосте, и студенту |
| 🧱 | **Разбор `index.html` на модули** и сборка в один файл | 2500 строк в одном файле тормозят любую доработку |
| 🤖 | **Telegram-бот** поверх того же `docs/data/` | нулевая стоимость: данные уже статические |
