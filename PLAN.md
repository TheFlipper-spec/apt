# План работ

## 0. Диагноз главного бага (подтверждён данными репозитория)

`fetch_all.py` решал, нужно ли перекачивать день, по **mtime файла**:

```python
if time.time() - os.path.getmtime(path) < 25 * 60:
    skipped += 1
    return True
```

В GitHub Actions `actions/checkout` создаёт рабочее дерево заново, поэтому у
**каждого** файла mtime равен времени чекаута. Условие всегда истинно →
существующие дни не перезапрашиваются никогда. Дата скачивалась ровно один раз —
в момент, когда впервые попадала в окно `-1..3`, то есть **за 3 дня до себя**,
когда расписание ещё не опубликовано. Дальше файл замораживался с
`published: false, pairs: []`.

Доказательство (`fetchedAt` внутри JSON, 82–91 групп на дату):

| дата | когда скачана | пар |
|---|---|---|
| 2026-10-01 | 01.10 23:57 | есть |
| 2026-10-02 | 01.10 23:57 | есть |
| 2026-10-03 | 01.10 23:57 | 0 |
| 2026-10-05 | 01.10 23:58 | 0 |
| 2026-10-06 | 02.10 21:18 | 0 |
| 2026-10-07 | 03.10 22:07 | 0 |

Косвенное подтверждение: прогоны бота занимают 11–18 секунд вместо ~2 минут —
он не делает сетевых запросов.

## 5. Что нашли уже сами тесты

Баги, которые не были видны глазами и всплыли при прогоне:

- `initPwa()` падал там, где `navigator.serviceWorker` существует как ключ,
  но равен `undefined` (небезопасный контекст, часть приватных режимов).
  Исключение в `boot()` обрывало инициализацию — страница оставалась пустой.
- Первый клик по карточке группы проглатывался: сторож длинного нажатия
  стартовал со значением `null` и трактовал любой клик без предшествующего
  `pointerdown` (клавиатура, скринридер) как «уже сработало избранное».
- Домашнее задание подгруппы подписывалось склеенным названием пары
  («03.03/09.0 · ПрофИнЯз») вместо своего предмета и номера подгруппы.

## 6. Чего не может сделать агент

У токена нет права `workflows`, поэтому `.github/workflows/update.yml` нужно
поправить вручную — расширить окно дат:

```yaml
- run: python3 fetch_all.py --weeks 2 --workers 6
```

Без этого бот продолжит ходить только на `-1..+3` дня: главный баг всё равно
исправлен, но обзор недели будет частично пустым.
